如何获取 GitHub Gist Token？

  1. 登录 GitHub，打开 Settings → Developer settings → Personal access tokens → Tokens (classic)。
  2. 点击 Generate new token (classic)，填写备注名称。
  3. 在权限列表中仅勾选 gist 复选框即可（安全最小权限）。
  4. 生成后复制以 ghp_ 开头的字符串粘贴到本工具中（凭证仅保存在你当前浏览器的 localStorage 中，不会发送至任何第三方服务器）。
