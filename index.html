GistSync 使用指南 & 原理说明

1 如何获取 GitHub Personal Access Token？

  1. 登录 GitHub，点击右上角头像进入 Settings（设置）。
  2. 在左侧菜单最底部点击 Developer settings（开发者设置）。
  3. 选择 Personal access tokens → Tokens (classic)。
  4. 点击 Generate new token (classic)，填写备注名称。
  5. 在权限列表中务必勾选 gist 复选框，然后点击底部生成按钮。
  6. 复制生成的 ghp_... 令牌粘贴到本工具配置栏中（仅保存在您的浏览器本地）。

2 二进制文件（图片/压缩包/PDF）同步机制

GitHub Gist 原生仅支持存储 UTF-8 纯文本。当您上传非文本文件时，本工具会自动将其转换为带有元数据头的 Base64 格式（前缀 __GISTSYNC_B64__）进行存储；在下载时自动识别并还原为原始二进制文件流。建议单文件大小控制在 10MB 以内以确保最佳 API 响应速度。

3 常见问题排查

  • 401 Unauthorized：Token 无效、已过期或未包含 gist 权限。
  • 404 Not Found：Gist ID 填写错误，或者访问私有 Gist 时未填写对应账号的 Token。
  • 403 Rate Limit：GitHub API 请求频率受限（已认证账号每小时 5000 次）。
